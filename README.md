# Listas de Análise de Séries Temporais

Repositório com as listas de Análise de Séries Temporais (GET00127) da UFF, resolvidas em R.

## Listas

| Pasta | Data | Conteúdo |
|---|---|---|
| Lista 1 | 07/08/2026 | Ruído branco, passeio aleatório e conjuntos cilíndricos |
| Lista 2 | 14/08/2026 | Ruído branco, passeio aleatório e AR(1), com FAC empírica e teórica |
| Lista 3 | 21/08/2026 | Série com tendência polinomial, média móvel e FAC |
| Lista 4 | 28/08/2026 | Decomposição com tendência e sazonalidade, OLS, diagnóstico e previsão |

Cada pasta contém o PDF da lista, os códigos em R e os gráficos gerados. As Listas 2, 3 e 4 também têm um README próprio com a explicação dos exercícios e dos resultados.

## Como executar

No RStudio, abrir a pasta da lista desejada como diretório de trabalho e executar:

```r
source("main.R")
```

Na Lista 1 o arquivo principal se chama `main_plot.R`, como pede o enunciado.
